# فروشگاه لوازم جانبی موبایل

یک پروژه فروشگاهی کامل با Django

## 🚀 امکانات پروژه

- صفحه اصلی با نمایش محصولات ویژه و جدید
- لیست محصولات با فیلتر پیشرفته (دسته، برند، قیمت، جستجو، مرتب‌سازی)
- جزئیات محصول با نمایش قیمت، تخفیف، رنگ‌ها و گارانتی
- سبد خرید با پشتیبانی از کاربران لاگین و مهمان
- ثبت سفارش با بررسی موجودی و کم کردن خودکار
- پنل کاربری با مشاهده سفارش‌های قبلی و جزئیات
- پنل ادمین برای مدیریت محصولات، دسته‌بندی‌ها و سفارشات
- طراحی ریسپانسیو و کاملاً واکنش‌گرا

## 🛠️ تکنولوژی‌ها

- بک‌اند: Django 6.0.6 (Python)
- فرانت‌اند: HTML5, CSS3, JavaScript
- دیتابیس: SQLite
- مدیریت تصاویر: Pillow
